## 📖 Sobre o Projeto

O **Cofvee** é uma landing page criada para um serviço de assinatura mensal de café. O projeto simula a venda de uma caixa personalizada com novos produtos que chega ao endereço cadastrado de forma cômoda e prática. 

A página foi pensada para jovens adultos, empresas e apaixonados por café que não abrem mão da bebida na rotina. O objetivo principal é permitir que os assinantes descubram, testem e experimentem novos produtos de forma personalizada e com ótimo custo-benefício.

## 🌟 Destaques do Projeto
- Design totalmente responsivo (adapta-se a celulares, tablets e computadores).
- Navegação interna suave (Smooth Scroll) através do menu.
- Efeitos visuais interativos (Hover) em botões e cartões de vantagens.
- Estruturação semântica e moderna.

## 💻 Tecnologias Utilizadas
- **HTML5:** Estrutura e semântica da página.
- **CSS3:** Estilização, layout com Flexbox e Media Queries.
